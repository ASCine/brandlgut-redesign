# Original images (backup)

Untouched copies of every photo, icon and the logo exactly as they are served by the live site
brandlgut.com (downloaded 13 October 2026), with their original file names and folders.

Nothing in the build reads from this folder and nothing should ever write to it. The working copies
used by the build are in `src/images/original/` (same files, web-safe file names); the colour matching
and WebP conversion only ever write to `docs/assets/img/`.
